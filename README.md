# Constraint solving algorithm

Constraint solving algorithm(CSP) is a approach to solve linear programming problems. This project mainly focus on simulating windows partition in a limited space and using Cassowary as the main algorithm. The [wikipedia](https://en.wikipedia.org/wiki/Cassowary_(software)) page sort out the knowledges of information you need to know.

## How to run

The language using is rust so it is well-known to install cargo. You can easily running by:

```
$ cargo run [--release]
```
